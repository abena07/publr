# Issue #4 — Initialize FastAPI Python project

## Step 1: Create the virtual environment

```bash
python3 -m venv .venv
source .venv/bin/activate
```

You'll know it worked when your terminal prompt shows `(.venv)` at the start.
You'll need to run `source .venv/bin/activate` every time you open a new terminal.

---

## Step 2: Install dependencies

```bash
pip install fastapi "uvicorn[standard]" google-api-python-client google-auth-httplib2 google-auth-oauthlib boto3 Pillow APScheduler httpx python-dotenv
```

Then freeze them so anyone can reinstall later:

```bash
pip freeze > requirements.txt
```

---

## Step 3: Create the folder structure

```bash
mkdir -p app/watchers app/publishers app/routes app/utils
touch app/__init__.py
touch app/watchers/__init__.py
touch app/publishers/__init__.py
touch app/routes/__init__.py
touch app/utils/__init__.py
```

The `__init__.py` files tell Python "this folder is a package" — they can stay empty.

---

## Step 4: Create `processed.json`

```bash
echo '{ "fileIds": [] }' > processed.json
```

This file tracks which Drive photos have already been published so you don't double-post.

---

## Step 5: Create `.env.example`

Create a file called `.env.example` (this is a template — real secrets go in `.env` which you never commit):

```
# Google Drive
GOOGLE_SERVICE_ACCOUNT_JSON=<path or stringified JSON>
GDRIVE_FOLDER_ID=<target folder ID>

# Cloudflare R2
R2_ACCOUNT_ID=
R2_ACCESS_KEY_ID=
R2_SECRET_ACCESS_KEY=
R2_BUCKET_NAME=
R2_PUBLIC_URL=<https://your-bucket.r2.dev>

# Instagram
INSTAGRAM_USER_ID=
INSTAGRAM_ACCESS_TOKEN=<long-lived token>

# Server
PORT=8000
POLL_INTERVAL_MINUTES=5
```

Then copy it to create your real env file:

```bash
cp .env.example .env
# now open .env and fill in the real values
```

---

## Step 6: Create `app/main.py`

Create `app/main.py` with just enough to confirm the server runs:

```python
from fastapi import FastAPI
from dotenv import load_dotenv

load_dotenv()

app = FastAPI(title="publr")

@app.get("/health")
def health():
    return {"status": "ok"}
```

---

## Step 7: Run the server

```bash
uvicorn app.main:app --reload --port 8000
```

- `http://localhost:8000/health` → should return `{"status":"ok"}`
- `http://localhost:8000/docs` → free interactive API explorer, auto-generated by FastAPI

---
